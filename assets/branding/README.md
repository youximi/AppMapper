# AppMapper 品牌图标

两个源 SVG 来自项目提供的图标素材，原样保存，主体颜色为 `#445785`，视框为 `72×72`。

| 源素材 | 用途 |
| --- | --- |
| `appmapper-mark.svg` | 透明主体，导出 Android 启动图标前景、主题化单色图标和通知剪影 |
| `appmapper-icon.svg` | 白色圆底完整图标，导出 Windows 图标、两端应用内品牌图标，并用于项目文档 |

Android 启动图标使用 108dp 画布，将原 72dp 视框居中后放大主体 1.08 倍，保留中央 66dp 安全区。白色背景是独立图层，由桌面决定最终形状。Android 13 及以上另提供同尺寸的单色主体。通知使用 24dp 白色透明剪影，主体放大 1.2 倍以减少留白。应用内图标保留蓝色与白底，使用 Image 显示，不跟随主题着色。

启动图标在 `mipmap-anydpi-v26/ic_launcher.xml` 中同时声明单色层，由支持的系统和桌面使用。SVG 的偶奇裁切区域导出成内外轮廓方向相反的非零填充路径，以兼容项目使用的 Compose 裁切解析，同时保留原图的透明间隙。

Windows ICO 包含 16、20、24、32、40、48、64、128、256px 九个尺寸。16–24px 的主体放大 1.1 倍，圆底保持原大小；其余尺寸保持原比例。ICO 同时作为 EXE 图标和 WPF 内嵌资源，用于窗口和托盘。256px PNG 用于关于页面和标题栏。标题栏控件匹配 WPF-UI 的 16dp 高度，以高质量缩小 PNG；避免 ICO 被当作普通图片时只读取 16px 首帧，以及 24dp 控件在 16dp 容器中被裁切。

更新源 SVG 后，从项目根目录运行：

```powershell
pwsh -NoProfile -File assets/branding/export-icons.ps1
```

上述命令使用 Windows 上的 PowerShell 7，需要当前环境允许执行本地脚本。导出使用系统 WPF，支持这两份源文件的路径、圆形、平移、偶奇填充与裁切，无额外图像处理包。生成结果随仓库管理，日常 Android/Windows 构建无需运行导出脚本。

导出后检查小尺寸、深浅背景、圆形和圆角方形裁切，尤其是两个重叠图形之间的透明间隙。品牌图标用于 AppMapper 客户端和 Windows 总控端；映射窗口继续显示被映射手机应用的图标。
